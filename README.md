# 고교학점제 정리하기 · GitHub Pages 업로드 안내

이 폴더의 파일을 압축 해제한 뒤, 모든 파일과 `assets` 폴더를 GitHub 저장소의 최상위에 올립니다.

1. GitHub에서 새 저장소를 만들고 공개(Public)로 설정합니다.
2. 압축을 풀어 나온 `index.html`, `style.css`, `app.js`, `assets` 폴더, `고교학점제-정리하기.html`, `.nojekyll`을 저장소 최상위에 올립니다.
3. 저장소에서 **Settings → Pages**로 이동합니다.
4. **Build and deployment → Deploy from a branch**를 고르고, `main` 브랜치와 `/(root)`를 선택해 저장합니다.
5. Pages 화면에 발급된 `https://사용자이름.github.io/저장소이름/` 주소를 학생에게 공유합니다.

정리하기 메뉴는 `고교학점제-정리하기.html` 페이지로 연결됩니다. 입력한 과목과 이유는 학생 기기의 브라우저에만 저장되며, 서버로 제출되지 않습니다. 페이지 아래 **내 기기에 저장된 내용 삭제** 버튼으로 해당 브라우저의 저장 내용을 삭제할 수 있습니다.

GitHub Pages 사이트 자체는 웹에 공개됩니다. 입력 데이터는 게시 파일이나 저장소에 기록하지 않습니다.
